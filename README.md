##  Обзор проекта
Данный репозиторий содержит результаты учебной практики, целью которой был анализ деятельности оптовой торговой компании и разработка решения по интеграции ключевых информационных систем: **CRM** и **ERP**.

##  Анализ предприятия
В ходе работы был проведен аудит ИТ-инфраструктуры объекта практики:
* **Предметная область:** Оптовая торговля.
* **Бизнес-процесс:** «Обработка заказа клиента и передача в производство/склад».
* **Проблема:** Рассинхронизация данных между отделом продаж и складом.

##  Техническое решение
Для решения задачи автоматизации была спроектирована интеграционная шина, использующая методы:
* **REST (Representational State Transfer):** для оперативного обмена данными.
* **JSON:** как основной формат передачи объектов (заказов, данных о клиентах).
* **Validation Layer:** встроенный модуль проверки данных на соответствие стандартам кодирования.

##  Программная реализация
Проект написан на **Python** и включает в себя:
1. **Модуль CRM:** генерация лидов и заказов.
2. **Модуль ERP:** управление складскими остатками и статусами производства.
3. **Интеграционный шлюз:** обеспечивает «бесшовную» передачу данных между системами.
